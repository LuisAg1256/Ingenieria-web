# Taller: XAMPP y WordPress

## ¿Qué es XAMPP?

XAMPP es un programa que nos permite simular un servidor web en nuestra propia computadora. Es muy útil para desarrollar sitios web sin necesidad de estar conectado a internet.

### ¿Qué significa XAMPP?

- **X**: multiplataforma (funciona en Windows, Linux y macOS)
- **A**: Apache (servidor web)
- **M**: MySQL o MariaDB (base de datos)
- **P**: PHP (lenguaje de programación)
- **P**: Perl (otro lenguaje)

Con XAMPP podemos ejecutar páginas web en PHP y usar bases de datos como si estuviéramos en un servidor real.

---

## ¿Qué es WordPress?

WordPress es un sistema para crear páginas web de forma fácil, sin necesidad de saber mucho código. Se usa mucho para blogs, páginas personales y hasta tiendas en línea.

### Ventajas de WordPress

- Es gratuito
- Es fácil de usar
- Tiene muchos temas y plugins
- Puedes crear desde un blog hasta una tienda online

---

## ¿Cómo usar WordPress con XAMPP?

Con XAMPP podemos instalar WordPress en nuestra PC para probar y desarrollar sitios sin necesidad de internet.

### Instalaciones:

1. **Instalar XAMPP**
   - Descargar desde [apachefriends.org](https://www.apachefriends.org)
   - Instalar y abrir el Panel de Control
   - Encender **Apache** y **MySQL**

2. **Descargar WordPress**
   - Desde [wordpress.org](https://wordpress.org)
   - Copiar la carpeta descomprimida en `C:\xampp\htdocs\`
   - Por ejemplo: `C:\xampp\htdocs\miweb`
